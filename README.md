# 词表速筛-即用

浏览器打开vocabtrim-instant.html即可开始使用

vocabtrim-ielts.html是已内置有道和新东方两个雅思词表的版本

词表格式依照、常用词表下载：https://github.com/kajweb/dict

一般单词应用功能太臃肿形成干扰。
一个超轻量单词工具，只保留最核心的功能：看词，删词。
